**AI Task Management System**
**Project Overview**

The AI Task Management System is a Data Science and Machine Learning project developed as part of my **Infyntrek Data Science & Machine Learning Internship**.
The system uses machine learning techniques to analyze and classify tasks based on their characteristics. It is designed to help users organize tasks, predict task priority, and support efficient task management.

## Objectives
- Classify tasks using machine learning techniques.
- Predict the priority of tasks.
- Analyze task-related information.
- Preprocess and clean task data.
- Build and evaluate a machine learning model.
- Provide a simple interface for interacting with the system.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
- Machine Learning
- Streamlit
- Matplotlib
- Seaborn
